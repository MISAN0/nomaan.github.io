Security tool

API Exposure Auditor

2026 · Solo

Checks an API for the mistakes that tell an attacker how it works before they send a single request: public Swagger and OpenAPI documentation, permissive CORS, missing security headers, chatty errors.

Problem
Published API documentation and loose server settings hand an attacker a map. Most teams never check what their own API gives away.
Approach
Read thirteen sources first, mapped the risks to the OWASP API Security Top 10 and CWE-200, then wrote one check per risk.
Result
Run against OWASP Juice Shop, a deliberately vulnerable test app, it reported 12 findings: 6 medium, 6 low, each with evidence. Output is a JSON report a pipeline can read.

Python · REST APIs · OpenAPI · OWASP
